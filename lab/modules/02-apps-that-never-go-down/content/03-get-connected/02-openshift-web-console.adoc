= OpenShift web console
:source-highlighter: highlightjs

You find yourself in the OpenShift web console already and you were able to find
the interactive labs. Congrats, you know your way around quite well already!

TIP: If the left navigation panel is not visible after logging in, click the *≡* icon in
the top-left corner to expand it. You only need to do this once.
